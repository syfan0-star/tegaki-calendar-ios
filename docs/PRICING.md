# てがきカレンダー iPad アプリ版 価格の仮説

版 0.1（2026-10-11）。**価格は本人が決めます。** この文書は決めるための材料で、数字はすべて「仮」です。
設計の前提（サブスクリプション、導入オファーによる無料試用、閲覧専用モード）は [DESIGN.md §7](DESIGN.md#7-課金storekit-2) にあります。

## 1. 競合の価格（2026 年 10 月時点の調べ）

| アプリ | 形態 | 価格 | 備考 |
| --- | --- | --- | --- |
| Pencil Planner | サブスク | 月 550 円 ／ 年 2,100 円 | 手書き手帳の代表格。年額は月額の約 3.2 か月分 |
| Planner for iPad | サブスク | 月 480〜700 円 | プランで幅がある |
| CalenGoo | 買い切り | 1,100 円 | 手書きは主役ではない。Google 連携が強い |

読み取れること:

- 手書き手帳の相場は **月 500 円前後、年 2,000〜2,500 円**。
- 年額は「月額の 4〜8 か月分」が多く、年払いを強く勧める作りになっている。
- 買い切りは 1,000 円台。買い切りだと OS 対応の費用が続かないので、本アプリはサブスクに決めた（[DESIGN.md §1.1](DESIGN.md#11-決定事項2026-10-11本人の決定)）。

## 2. 提案（仮）

| 項目 | 提案 | 考え方 |
| --- | --- | --- |
| 月額 | **300 円** | 相場より安め。「紙の手帳の代わり」として気軽に始められる額。初めての個人販売で、機能が相場の製品より少ない（Google 固有機能が無い）ことも織り込む |
| 年額 | **2,400 円**（月あたり 200 円、月額の 8 か月分） | 年払いを選ぶ動機（33% 引き）を作る。相場の下限に近い |
| 無料試用 | **14 日間**（App Store の導入オファー） | 月の切り替わりを一度またぐと「行が伸びる」月ページの価値が分かる。試用中に解約すれば無料 |
| 値上げ | 公開後 1 年は据え置き。機能が増えたら新規の人だけ値上げ（既存の購読者は Apple の仕組みで据え置きにできる） | |

価格は App Store Connect の **価格表にある金額から選びます**（Apple が決めた「価格ポイント」。300 円はありますが、2,400 円が無い場合は近い金額（2,300 円か 2,500 円）に寄せます）。他の国の価格は Apple が為替で自動換算します（日本中心の配信なので、ほぼ気にしなくてよい）。

## 3. Apple の手数料と受取額

### 3.1 手数料

| 条件 | 手数料 |
| --- | --- |
| 通常 | 30% |
| **App Store Small Business Program に申し込む**（前年の売上 100 万ドル未満。本アプリは確実に該当） | **15%** |
| 同じ人が 1 年を超えて購読を続けた分 | 申込に関係なく 15% |

- Small Business Program は **本人が App Store Connect で申し込む**必要があります（Paid Apps Agreement への同意が先。[APPLE_ENROLLMENT.md 4-4](APPLE_ENROLLMENT.md)）。承認されると、概ね翌月の売上から 15% になります。**公開前に申込を済ませる**のが肝心です。
- 以下の計算は **15% が適用された前提**です。

### 3.2 1 件あたりの受取額（概算）

日本の App Store の表示価格は消費税（10%）込みです。Apple は税抜き額から手数料を引いて開発者に払います。

```
受取額 ≒ 表示価格 ÷ 1.10 × (1 − 手数料)
  月額 300 円   → 272.7 × 0.85 ≒ 232 円   （30% なら 191 円）
  年額 2,400 円 → 2,181.8 × 0.85 ≒ 1,855 円 （30% なら 1,527 円）
```

実際の受取額は App Store Connect の価格表に「開発者の収益」として円単位で出ます（数円の差はあり得ます）。

### 3.3 受取額の試算表

前提（変えてよい数字）:

- 払っている人のうち **年額 40%・月額 60%**。
- 「残り続ける」= 月額の人も 12 か月払い続ける。「途中でやめる」= 月額の人は平均 6 か月で解約、年額の人は 1 年は払う。
- 無料試用から有料に進む人を **3 人に 1 人**とすると、払っている人 10 人を得るには試用を始める人が約 30 人要る。

| 払っている人数 | 1 年の受取（残り続ける） | 1 年の受取（途中でやめる） | 固定費を引いた残り（残り続ける） |
| --- | --- | --- | --- |
| 10 人 | 約 24,100 円 | 約 15,800 円 | 約 11,300 円 |
| 50 人 | 約 120,600 円 | 約 78,900 円 | 約 107,800 円 |
| 200 人 | 約 482,500 円 | 約 315,400 円 | 約 469,700 円 |

計算: 1 人あたり年間 = 0.6 × (232 × 12) + 0.4 × 1,855 ≒ 2,412 円（残り続ける）／ 0.6 × (232 × 6) + 0.4 × 1,855 ≒ 1,577 円（途中でやめる）。固定費は §4 の 12,800 円。

**損益分岐**: 年間の固定費 12,800 円を払っている人の受取で割ると、**6 人** が 1 年払い続ければ元が取れます（残り続ける前提）。

## 4. 固定費

| 費目 | 年額 | 備考 |
| --- | --- | --- |
| Apple Developer Program | 99 米ドル ≒ **12,800 円**（Apple Developer アプリの表示額。確定額は決済画面） | 毎年。切れると App Store から消える |
| 独自ドメイン | **不要になった**（0 円） | Google の審査（独自ドメインのホームページが必要）を EventKit 採用で回避したため。規約・プライバシーは既存の GitHub Pages に置く |
| サーバー | 0 円 | 手書きは本人の iCloud（CloudKit プライベート DB）。開発者側の費用なし |
| ビルド環境 | 0 円 | GitHub Actions は公開リポジトリなら無料 |
| 開発に使う Mac・iPad・Apple Pencil | 0 円（手持ち） | |
| **合計** | **約 12,800 円／年** | |

これ以外に、売上が出たときの税金（§5）があります。

## 5. お金の流れで知っておくこと

| 項目 | 内容 |
| --- | --- |
| 入金 | Apple が **月ごと**にまとめて、翌月末〜翌々月初ごろに登録した銀行口座へ振り込む。少額のときは次の月に繰り越されることがある |
| 返金 | 利用者が Apple に申し出て Apple が判断する。返金分は次の入金から差し引かれる。開発者は関与できない（利用規約第 5 条のとおり） |
| 米国の源泉徴収 | App Store Connect の税務フォーム（日本在住の個人は通常 W-8BEN）を出せば、米国分の源泉徴収はかからない |
| 日本の税金 | 受取額は所得（給与がある人は通常「雑所得」）。年間 20 万円を超えると確定申告が必要になるのが一般的。消費税は年商 1,000 万円以下なら免税。**金額が大きくなってきたら税務署か税理士に確認**（この文書は税務の助言ではありません） |
| 価格の変更 | いつでも App Store Connect で変えられる。値上げは既存の購読者に Apple が通知し、同意が要る場合がある。値下げは即時 |
| 導入オファー（無料試用）の変更 | 期間（3 日〜1 年）と有無をいつでも変えられる。ひとりの Apple Account につき試用は 1 回 |

## 6. 本人が決めること

決定（2026-10-11、B-7）: 月額 300 円・年額 2,400 円（月あたり 200 円、「4 か月分お得」）・14 日間無料。M5 で実装（[M5_CONTRACT.md](M5_CONTRACT.md) §1.1、[M5.md](M5.md)）。¥2,400 が App Store Connect の価格表に無ければ ¥2,300（M5-7）。

1. 月額・年額の金額（§2 の案から、または別の金額）。
2. 無料試用の日数（14 日のままでよいか。7 日・1 か月も可）。
3. 公開時に年額だけ割引キャンペーンをするか（しないのが既定）。
4. Small Business Program の申込（本人の操作が必要。公開前に）。

決まったら [DESIGN.md §7.1](DESIGN.md#71-商品) の表と [TERMS.md 第 5 条](TERMS.md#第-5-条料金サブスクリプション) の【価格】を書き換えます。
