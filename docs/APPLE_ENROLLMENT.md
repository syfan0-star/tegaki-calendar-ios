# Apple Developer Program 登録手順（本人向け）

**要約**：App Store でアプリを売るには、Apple Developer Program（年会費制。Apple Developer アプリの表示は ¥12,800／年、公式サイトの表記は 99 米ドル／年。確定額は支払い画面で確認）に「個人」として登録し、承認されたあと、App Store Connect という Apple の Web サイトで「有料アプリの契約」「税務」「銀行口座」などを本人が設定します。登録は iPhone の「Apple Developer」アプリで行い、身分証を撮影して本人確認をします。承認までの日数は Apple が公表しておらず、数日〜数週間の幅があります。Claude は文書やプログラムの準備を代行できますが、パスワードやカード・口座・身分証を扱う操作、契約への同意は、本人にしかできません。

> **注記**：この文書は Claude（AI）が下書きしたものです。法律・税務の助言ではありません。税務フォームや銀行口座の項目で迷ったら、税務の専門家に確認してください。手順や金額は 2026 年 10 月 11 日時点の調べに基づきます。Apple の画面が変わっていたら、画面の案内を優先してください。

関連文書：[利用規約](TERMS.md) ／ [サポート](SUPPORT.md) ／ [プライバシーポリシー](PRIVACY.md)

## 全体の流れ

```
① 事前準備（Apple Account の確認、身分証、カード）
      ↓
② iPhone の「Apple Developer」アプリで登録（本人確認の撮影 → 支払い）
      ↓
③ 承認待ち（メールが来る）
      ↓
④ App Store Connect（Web）で本人が設定
   有料アプリの契約 → 税務フォーム → 銀行口座 → Small Business Program → EU の申告
      ↓
⑤ アプリの提出準備（Claude と一緒に）
```

## 0. 費用と期間の目安

| 項目 | 内容 |
| --- | --- |
| 年会費 | Apple Developer アプリ内の表示：**¥12,800／年**（公式サイト：99 米ドル／年）。確定額は支払い画面に出る金額です。毎年自動更新（止めることもできます）。 |
| 個人登録で公開される情報 | App Store の「販売者」欄に、**戸籍上の氏名**が表示されます（個人登録では避けられません。承諾済み）。住所・電話番号は、EU に配信しなければ表示されません。 |
| 承認までの日数 | Apple は公表していません。数日で済むこともあれば、数週間かかることもあります。 |
| 追加で必要になる費用 | ありません（iCloud の同期は利用者自身の iCloud 容量を使うため、開発者側のサーバー代はかかりません）。 |

## 1. 事前準備

登録を始める前に、次を確認してください。

- [ ] **Apple Account（旧 Apple ID）が 2 ファクタ認証になっている**
  - iPhone の「設定」→ 自分の名前 →「サインインとセキュリティ」→「2 ファクタ認証」がオン
- [ ] **Apple Account の名前が、戸籍上の本名と同じ**（漢字の表記も身分証と同じ）
  - 「設定」→ 自分の名前 →「名前、電話番号、メール」で確認・修正
  - ニックネームや旧姓、ローマ字だけの名前になっていると、本人確認で止まります
- [ ] **Apple Account の住所が、身分証の住所と同じ**
  - 「設定」→ 自分の名前 →「お支払いと配送先」の請求先住所
- [ ] **Apple Account の国／地域が「日本」**
- [ ] **顔写真付きの身分証**（運転免許証、マイナンバーカード、パスポートなど）。有効期限内で、氏名・住所が Apple Account と一致しているもの
- [ ] **本人名義のクレジットカード**（Apple Account の支払い方法に登録しておく。年会費はこのカードに請求されます）
- [ ] **iPhone**（「Apple Developer」アプリを入れて、身分証をカメラで撮影します。iPad でも可能な場合がありますが、iPhone が確実です）
- [ ] 登録に使うメールアドレスを決めておく（Apple からの連絡が来ます。Apple Account のメールです）

## 2. Apple Developer アプリでの手順

1. iPhone の App Store で **「Apple Developer」** アプリ（Apple 製、無料）を入れます。
2. アプリを開き、下の **「アカウント」** タブを押します。
3. 登録に使う Apple Account で **サインイン** します（2 ファクタ認証の確認コードが来ます）。
4. **「Apple Developer Program に登録」** を押します。
5. 画面の案内に従って進みます。
   - 「個人／個人事業主」を選びます（会社ではないので、D‑U‑N‑S 番号は不要です）。
   - 氏名・住所・電話番号を確認します。Apple Account の内容が出るので、身分証と同じか見てください。
6. **本人確認の撮影**：身分証の撮影を求められます。明るい場所で、文字がはっきり読める写真を撮ってください（顔写真の撮影を求められることもあります。画面の指示に従ってください）。
7. **Apple Developer Program 使用許諾契約** が表示されます。内容を確認して同意します（契約への同意は本人の操作です）。
8. **支払い**：年額（表示は ¥12,800。確定額は画面）を、Apple Account の支払い方法で購入します。「自動更新」のスイッチが出た場合は、お好みで（オフにすると翌年は手動で更新します）。
9. 「登録を処理中です」のような画面になれば完了です。アプリを閉じて構いません。

## 3. 承認待ち

- 承認されると、Apple Account のメールアドレスに **「Welcome to the Apple Developer Program」** のようなメールが届きます。
- 登録画面に「24 時間以内」などの目安が出ることがあります。**その目安を過ぎてもメールが来ないときは、問い合わせてください**：
  - Apple Developer アプリの「アカウント」タブに表示される状態を確認
  - <https://developer.apple.com/contact/> →「メンバーシップと アカウント」から連絡（日本語で書けます）
- 実際には数日〜数週間かかる例もあります。本人確認の写真が読めなかったときや、氏名・住所が一致しないときは、Apple からやり直しのメールが来ます。
- **待っている間にできること**：Claude がアプリのプログラム、GitHub Actions でのビルドの仕組み、App Store 用の文章（説明文・スクリーンショットの計画）を進めます。ただし、iPad に試作品を入れる（TestFlight）のは承認後になります。

## 4. 承認後に App Store Connect（Web）でやること

**App Store Connect**（<https://appstoreconnect.apple.com/>）は、アプリの登録・審査・売上を管理する Apple の Web サイトです。Safari で開き、同じ Apple Account でサインインします。以下はすべて **Account Holder（あなた本人）** でないとできない操作です。

### 4‑1. 有料アプリの契約（Paid Apps Agreement）に同意する

1. 上のメニュー →「契約／税金／口座情報」（Agreements, Tax, and Banking）を開きます。
2. **「有料 App」（Paid Apps）** の行の「同意する」を押し、契約の内容を確認して同意します。
3. これに同意しないと、有料アプリもサブスクリプションも出せません。

### 4‑2. 税務フォームを出す

1. 同じ「契約／税金／口座情報」の「税務」欄で、求められているフォームを開きます。
2. 日本に住む個人の場合、米国の **W‑8BEN**（「私は米国の居住者ではありません」と申告する書類）が求められます。英語ですが、氏名・住所・国籍などを入れる簡単なものです。
   - 「U.S. taxpayer identification number（米国の納税者番号）」は、米国の番号を持っていなければ空欄で構いません。
   - 「Foreign tax identifying number（外国の納税者番号）」や租税条約の項目で迷ったら、**税務の専門家に確認**してください。ここは Claude では判断できません。
3. 日本の税務フォームなど、他のフォームが画面に出た場合も、画面の説明に従って記入します。
4. 売上は Apple から支払われる「収入」になります。確定申告の要否・やり方は税務の専門家に相談してください。

### 4‑3. 銀行口座を登録する

1. 「口座情報」（Banking）欄で、売上の振込先の口座を登録します。
2. 用意するもの：本人名義の日本の銀行口座（銀行名、支店名、口座番号、**口座名義のローマ字表記**）。銀行によっては SWIFT コード／BIC を聞かれるので、銀行のサイトで調べておきます。
3. 通貨は日本円（JPY）を選びます。

### 4‑4. Small Business Program に申し込む

- Apple の手数料は通常 30% ですが、前年の売上が少ない開発者は **App Store Small Business Program** に入ると **15%** になります。
- 申込：<https://developer.apple.com/jp/app-store/small-business-program/> から、Account Holder が申請します（4‑1 の契約に同意した後でないと申し込めません）。
- 初めて登録した年は、売上の実績がなくても申し込めます。

### 4‑5. EU の「デジタルサービス法（DSA）」の申告：EU には配信しない

- EU 向けにアプリを配信する場合、EU の法律で「事業者（トレーダー）」の情報（住所・電話番号・メール）を App Store 上に公開する必要があります。
- 本アプリは **EU には配信しない**方針です（[利用規約 第 1 条](TERMS.md#第-1-条この規約について)）。
  1. App Store Connect に「トレーダーの状況」や「DSA」に関する確認が出たら、**トレーダー情報は登録しない**（登録すると公開されます）。
  2. アプリの「価格と配信状況」（Pricing and Availability）で、配信する国／地域から **EU の 27 か国のチェックを外す**（Claude が一覧を用意します）。
- EU に配信しなければ、住所や電話番号が公開されることはありません。

### 4‑6. App Store に載せるページの URL を用意する

アプリの登録時に、次の 2 つの URL が必要です。どちらも、既にある Web 版の GitHub Pages（`syfan0-star.github.io/tegaki-calendar/`）の中にページを足して公開します（新しい GitHub Pages は作りません。[設計書 付録 B-6](DESIGN.md#付録-b-要確認リスト本人の判断待ち)。Claude が準備し、公開の実行は事前に確認します）。

- **プライバシーポリシーの URL**：[PRIVACY.md](PRIVACY.md) を公開したページ（必須）
- **サポート URL**：[SUPPORT.md](SUPPORT.md) を公開したページ（必須）

## 5. Claude が代行できること／できないこと

| 代行できる | 本人にしかできない |
| --- | --- |
| アプリのプログラムを書く、ビルドの仕組み（GitHub Actions）を作る | Apple Account へのサインイン、2 ファクタ認証のコード入力 |
| 利用規約・サポート・プライバシーポリシーの下書き（この docs フォルダ） | 身分証の撮影、本人確認 |
| App Store の説明文・キーワード・スクリーンショット計画の作成 | 年会費の支払い（クレジットカード） |
| App Store Connect の各画面で「何を選べばよいか」を横で説明する | 契約（Program 使用許諾契約、Paid Apps Agreement）への同意 |
| 証明書・プロファイルの作成手順の案内、設定ファイルの用意 | 税務フォーム（W‑8BEN など）、銀行口座の入力 |
| 配信地域（EU を外す）の一覧作成、プライバシーラベルの回答案 | Small Business Program の申請 |
| 審査に返されたときの返答文の下書き | Apple への問い合わせの送信、審査への提出ボタン |

- パスワード・カード番号・口座番号・マイナンバーなどは、Claude に伝えないでください。Claude はそれらを入力する操作をしません。
- Apple や GitHub への「公開」「提出」「同意」にあたる操作は、Claude が代行できるものでも、必ず事前にあなたに確認してから行います。

## 6. よくあるつまずき

| つまずき | 対処 |
| --- | --- |
| **氏名が一致しない**（Apple Account がニックネーム・旧姓・ローマ字） | 登録前に「設定」→ 自分の名前 →「名前、電話番号、メール」で、身分証と同じ漢字の本名に直す。本人確認で差し戻されたら、直してから再提出。 |
| **住所の表記が違う**（マンション名の有無、番地の全角／半角、都道府県の省略） | 身分証の住所をそのまま写す。Apple Account の請求先住所も同じにしておく。 |
| **2 ファクタ認証がオフ** | 登録できません。先にオンにする（iPhone の「設定」→ 自分の名前 →「サインインとセキュリティ」）。 |
| **身分証の写真が読めない** | 反射・ぼけ・影に注意して撮り直す。パスポートなら顔写真のあるページ全体。 |
| **支払いが通らない** | Apple Account の支払い方法が本人名義のカードか、有効期限内かを確認。 |
| **メールが来ない** | 迷惑メールフォルダを確認。Apple Developer アプリの「アカウント」タブで状態を見る。目安の時間を過ぎていれば問い合わせ（第 3 章）。 |
| **「有料 App」の契約が見当たらない** | 承認直後は表示に時間がかかることがあります。少し待って再読み込み。 |
| **銀行口座の名義** | 口座名義は銀行に登録されたローマ字（通帳やキャッシュカードの表記）に合わせる。 |
| **税務フォームの項目が分からない** | 税務の専門家に確認。適当に埋めない。 |

## 7. 登録が済んだら

次のことを Claude に伝えてください（内容そのものは送らなくて構いません。「済んだ」だけで十分です）。

1. 承認メールが届いた
2. 有料 App の契約に同意した
3. 税務フォームと銀行口座を登録した
4. Small Business Program に申し込んだ
5. プライバシーポリシーとサポートページを公開してよい（公開の前に Claude が確認します）

その後、Claude が App Store Connect での「アプリの登録」「サブスクリプションの登録」「TestFlight で iPad に試作品を入れる」手順を、一歩ずつ案内します。
