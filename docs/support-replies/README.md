# サポートの返事の定型文（1.2 から）

英語などで届いた問い合わせに返事をするための定型文です（[M7B_CONTRACT.md](../M7B_CONTRACT.md) §6.7、M7B-11）。各ファイルに **英語の文** と、その **日本語の逆翻訳**（英語の文が何と言っているか）を並べてあります。本人は逆翻訳を読んで、送る文の中身を確かめます。

## 返事の流れ

1. 英語などのメールが syfan0@gmail.com に届く。
2. 本人が Claude に「このメールを訳して」と頼む（本文を貼るか、どのメールかを伝える）。
3. Claude が日本語の訳と要点（相手が何を求めているか、どの定型文が近いか、確かめが要ること）を出す。
4. 本人が、返事の中身を日本語で決める（どの定型文を使うか、足すこと・削ること）。
5. Claude が、相手の言語の返事と、その日本語の逆翻訳を作り、Gmail の **下書き** にする（相手の言語が英語以外なら、定型文の英語をその言語に訳して使う。逆翻訳はその言語の文から作る）。
6. 本人が逆翻訳を読み、よければ **自分で送る**。Claude は送らない。
7. 問い合わせが解決したら、そのメールと下書きと、そのメールを渡した Claude の会話を本人が消す（目安。プライバシーポリシー第 12 節の「必要がなくなったら消します」の約束。この流れでは本文が Claude との会話と下書きにも残るため。消す手順は [privacy-request.md](privacy-request.md) の「本人の手順」と同じ）。Claude のデータ利用の設定（モデルの改善に使うか）も 1 回見る。

決まり:

- 返事の言語は、相手が書いてきた言語（分からなければ英語）。どの返事も最後に「機械翻訳の助けを借りて書いた」ことを書く（英語のサポートページと同じ）。
- 返金はいつも Apple（開発者は返金できない）。EU（欧州連合）の撤回の権利の手続きも Apple（[refund.md](refund.md) の EU の段落）。開発者が手書きの中身を見ることも、戻すこともできない。
- 日付の約束（「来週直します」など）はしない。直すときは「次の更新で」とだけ書く。直すかどうかは本人が決める。
- 相手に手書きや予定の中身を送ってもらわない。写真を頼むときは「画面の写真」だけ。
- 本人の電話番号・住所は書かない（EU の App Store のページには出るが、返事には書かない）。署名は「Masataka Ikeda / Developer of Tegaki (てがきカレンダー)」。
- 訳の誤りや祝日の誤りの知らせは、リードが次の版の直しの一覧に記録する（祝日は [holiday-error.md](holiday-error.md) の判断表）。一覧には誤りの中身だけを書き、相手の名前・メールアドレス・メールの文は書かない（プライバシーポリシー第 12 節の「問い合わせに答えるためだけに使います」を守るため）。

## 定型文

| ファイル | 使う場面 |
| --- | --- |
| [cancel.md](cancel.md) | 解約のしかた |
| [refund.md](refund.md) | 返金してほしい（EU の段落とドイツの 1 文つき） |
| [restore.md](restore.md) | 購入が戻らない・端末を替えた |
| [language.md](language.md) | 表示の言語を変えたい・日本語（英語）に戻したい |
| [holiday-error.md](holiday-error.md) | 祝日が違う・出ない（判断表つき） |
| [translation-error.md](translation-error.md) | 訳がおかしい |
| [privacy-request.md](privacy-request.md) | 自分の情報を見せて・消して（本人の手順つき。1 か月以内に答える） |

`{name}` などの `{ }` は、その場で差し込む所です（相手の名前が分からなければ「Hello,」だけにする）。英語の画面の名前（Settings > Purchase > Restore Purchases など）は X の用語集と照らしてあります（[docs/store/README.md](../store/README.md) の「英語の画面の名前」）。

逆翻訳は、定型文を書いた A（`refund.md` の EU の段落とドイツの 1 文、`privacy-request.md` は LA2）が英語の文を日本語に訳し戻したものです（日本語の元を見ない R の逆翻訳ではありません）。実際の返事では、Claude がそのときの文からもう一度逆翻訳を作ります。
