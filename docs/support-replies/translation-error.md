# 訳がおかしい（translation-error）

使う場面: アプリや App Store の訳の誤りを知らされたとき（§6.1 の 8「誤訳の受け口」）。知らせは、リードが次の版の訳の直しの一覧に記録する（言語・画面・今の文・相手の案）。直すかどうか、いつ直すかは本人が決める。

## English

```text
Hello {name},

Thank you very much for telling me about the translation.

The translations in the app were made with AI and checked by translating them back into Japanese, but no native speaker has reviewed them yet. Your report is a great help.

So that I can fix it, could you tell me the following?

- the screen where you saw it (a screenshot helps)
- the text that is wrong
- the text that you would suggest

I plan to correct it in a future update of the app.

This reply was written with the help of machine translation. If anything is unclear, please let me know.

Best regards,
Masataka Ikeda
Developer of Tegaki (てがきカレンダー)
```

相手がもう画面と直し方を書いてきたときは、「So that I can fix it…」から 3 つの点までを、次の 1 文に替える:

```text
Thank you for the screenshot and your suggestion. I have noted them.
```

## 日本語（逆翻訳）

```text
{name} 様

訳について教えていただき、本当にありがとうございます。

アプリの訳は AI が作り、日本語へ訳し戻して確かめていますが、まだ母語の人の確認は受けていません。お知らせはとても助かります。

直すために、次のことを教えていただけますか。

- それを見た画面（画面の写真があると助かります）
- 誤っている文
- こうしたらよいという文

アプリの今後の更新で直すつもりです。

この返事は、機械翻訳の助けを借りて書いています。分かりにくいところがあれば、お知らせください。

よろしくお願いします。
池田 雅高
Tegaki（てがきカレンダー）の開発者
```

替える 1 文の逆翻訳:

```text
画面の写真と、直し方の案をありがとうございます。書き留めました。
```
