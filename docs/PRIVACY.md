# てがきカレンダー プライバシーポリシー（アプリ版）

**要約**：iPad・iPhone 用のアプリ「てがきカレンダー」は、あなたの情報を**何も集めません**。開発者のサーバーはなく、アカウント登録もなく、広告や解析の仕組みも入っていません。手書きと設定は、あなたの端末（iPad・iPhone）の中と、あなた自身の iCloud にだけ保存され、開発者は見ることができません。予定は端末の「カレンダー」から読み書きしますが、そのデータがアプリの外に送られることはありません。料金は Apple が扱い、開発者はカード情報を受け取りません。

## 1. 開発者が集める情報：ありません

- 本アプリは、あなたの名前・メールアドレス・位置情報・端末の識別子・使い方の記録などを、一切集めません。
- 開発者のサーバーはありません。アプリが通信する相手は、Apple の iCloud（あなた自身の保存領域）と、Apple の App Store（購入の確認）だけです。
- iCloud の変更を知るために Apple のプッシュ通知の仕組み（サイレント通知）を使いますが、画面に通知は表示されず、通知に内容も含まれません。
- 広告はありません。アクセス解析や行動追跡（トラッキング）の仕組みも入っていません。他社の SDK（部品プログラム）も使っていません。
- アカウント登録やログインはありません。

## 2. データの保存場所：あなたの端末と、あなたの iCloud

| データ | 保存場所 | 開発者から見えるか |
| --- | --- | --- |
| 手書き（線のデータ） | 端末内、および iCloud（プライベートデータベース） | 見えません |
| 設定（ペンの色、表示するカレンダーなど） | 端末内 | 見えません |
| 予定の控え（表示を速くするための一時的なもの） | 端末内 | 見えません |
| 購読の状態 | Apple が管理。アプリは Apple から「有効か」と期限を受け取る | 見えません |
| 購読の状態の控え（最後に確認した状態と日時） | 端末内（UserDefaults） | 見えません |

- **iCloud（プライベートデータベース）**とは、Apple が用意している、あなたの Apple Account 専用の保存領域です。Apple の説明では、ここに入れたデータは開発者の管理画面に表示されず、あなたの iCloud 容量として数えられます。iCloud にサインインしていないときは、端末内だけに保存されます。
- 開発者は、あなたの手書きや予定を受け取らず、閲覧・復元・削除のどれもできません。

## 3. カレンダーへの「フルアクセス」をお願いする理由

初めて使うときの案内の中で「許可の画面を出す」を押すと、iOS・iPadOS が「カレンダーへのフルアクセスを許可しますか？」と聞きます（アプリが勝手に出すことはありません）。

- **なぜフルアクセスか**：iOS・iPadOS には、予定を「読むだけ」の権限がありません。予定を画面に表示するだけでも、Apple の仕組み上「フルアクセス」が必要です。
- **何に使うか**：
  - 予定を日・週・月・年のページに表示するため
  - あなたが手書きから作った予定を、あなたが選んだカレンダーに保存するため
  - あなたが編集・削除した予定を反映するため
- **何をしないか**：予定の中身を、端末の外（開発者やその他の誰か）に送ることはありません。あなたが操作していないときに、勝手に予定を作ったり変えたりすることもありません。
- **Google カレンダーについて**：アプリは Google とつながりません。端末の設定アプリに追加した Google アカウントを iOS・iPadOS が同期し、その結果を端末の「カレンダー」から読んでいます。Google 側での扱いは Google のプライバシーポリシーに従います。
- **許可の取り消し**：「設定」→「プライバシーとセキュリティ」→「カレンダー」→「てがきカレンダー」で、いつでも変えられます。取り消すと予定は表示されませんが、手書きはそのまま使えます。

## 4. 手書きと Apple Pencil

- 手書きは「線の座標」として保存されます。文字として読み取って解析したり、どこかに送ったりすることはありません。
- 予定のタイトル欄に Apple Pencil で書くと文字に変わるのは、iPadOS の「スクリブル」機能によるもので、端末の中で処理されます。
- Apple Pencil のダブルタップやスクイーズの動作は、「設定」→「Apple Pencil」の設定を読み取って従います。これも端末の中だけの処理です。
- 設定の「手書きを書き出す」で作るファイル（JSON・PDF）は、あなたが共有シートで選んだ先（「ファイル」アプリ、AirDrop、メールなど）にだけ渡ります。開発者には送られません。データファイル（JSON）には手書きの線と、どの端末で書いたかを区別する印（このアプリ用のランダムな識別子。端末の名前やシリアル番号ではありません）が入ります。

## 5. 購入と料金について

- サブスクリプションの購入・請求・解約・返金は Apple が行います。開発者は、あなたのカード番号や請求先住所を受け取りません。
- 開発者が Apple から受け取るのは、個人を特定できない形の売上の集計だけです。
- 無料試用の資格（以前に試用したか）は Apple が判定し、アプリには「対象か否か」だけが伝わります。

## 6. 第三者への提供：ありません

- 開発者は、あなたのデータを誰にも渡しません（そもそも持っていません）。
- Apple の iCloud と App Store は、あなたと Apple との契約に基づいて動いています。これらは Apple のプライバシーポリシー（<https://www.apple.com/jp/legal/privacy/>）に従います。

## 7. Apple を通じて届くことがある情報

- iOS・iPadOS の「設定」→「プライバシーとセキュリティ」→「解析と改善」で「App デベロッパと共有」をオンにしている場合、アプリが不意に終了したときの情報（クラッシュの記録）を Apple が集め、個人を特定しない形で開発者に見せることがあります。これは Apple の仕組みで、あなたがオフにできます。
- App Store のレビューや評価は、Apple の仕組みで公開されるもので、本アプリが集めるものではありません。

## 8. 子どもの利用

本アプリは子ども向けには作られておらず、子ども向けのカテゴリには登録しません。年齢を問わず、本アプリは個人情報を集めません。

## 9. データの削除

- アプリの設定の「この端末の手書きを全て消す」で、端末と iCloud の両方から手書きを消せます。
- アプリを削除すると、端末内のデータは消えます。iCloud 側は、「設定」›「Apple Account」›「iCloud」›「アカウントのストレージを管理」›「てがきカレンダー」（iOS・iPadOS 17 では「Apple ID」）から消せます。
- アプリで作った予定は、ふつうのカレンダーの予定として残ります。消すときは「カレンダー」アプリや Google カレンダーから削除してください。
- 手順の詳細は[サポートページ](SUPPORT.md#自分のデータを全部消すには)にあります。開発者にはデータがないため、開発者への削除依頼は必要ありません。

## 付録 A　Web 版との違い

ブラウザで動く Web 版「手書きカレンダー」は、Google にログインして Google カレンダーと Google ドライブに直接つなぐ仕組みでした（Web 版のポリシー：<https://syfan0-star.github.io/tegaki-calendar/privacy.html>）。アプリ版は、Google へのログインも Google ドライブへの保存もしません。Google カレンダーの予定は iOS・iPadOS を通じて、手書きは iCloud に保存されます。

## 付録 B　App Privacy（App Store の「プライバシー」欄）の回答案

App Store Connect では、アプリが集めるデータの種類を申告します（「プライバシーラベル」）。本アプリの回答案は次のとおりです。

| App Store Connect の質問 | 回答案 | 理由 |
| --- | --- | --- |
| このアプリ（または連携する第三者）はデータを収集しますか？ | **いいえ** | 開発者のサーバーはなく、データを受け取る仕組みがない |
| 結果として表示されるラベル | **「データは収集されません」（Data Not Collected）** | |
| トラッキング（追跡）をしますか？ | **いいえ** | 広告・解析 SDK なし |
| プライバシーポリシーの URL | <https://syfan0-star.github.io/tegaki-calendar/app/privacy.html> | 5.1.1 の必須項目 |

- **考え方**：Apple の定義では「収集」とは、データを端末の外に送り、開発者や第三者が後から利用できる状態にすることです。本アプリでは、予定は端末内の「カレンダー」との読み書きだけ、手書きは利用者本人の iCloud（開発者が触れない領域）への保存だけなので、「収集」に当たらないと考えます。
- **審査で聞かれたときの説明文（案）**：「本アプリにはサーバーがありません。カレンダーのデータは EventKit で端末内の予定を表示・編集するためだけに使い、端末外へ送信しません。手書きデータは利用者自身の iCloud プライベートデータベースに保存され、開発者はアクセスできません。解析・広告・第三者 SDK は含みません。」
- **カレンダー権限の説明文**（許可を求めるときに iOS・iPadOS が表示する文）：「カレンダーの予定を手帳のページに表示し、手書きから予定を作るために使います。iOS と iPadOS には読み取りだけの許可が無いため、フルアクセスをお願いしています。予定はこの端末の中だけで扱い、外部には送りません。」
